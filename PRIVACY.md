# Privacy Policy

This is a personal, self-built, non-commercial tool. It is not offered as a
product or service to the public.

**What data is collected:** the owner's own phone number, stored only in a
private configuration file on the owner's own infrastructure, used solely to
send the owner automated account-activity notifications (e.g. trade
confirmations, daily summaries) about the owner's own brokerage account.

**Sharing:** this data is never shared, sold, or used for marketing, and is
never provided to any third party other than the SMS carrier/provider (Twilio)
strictly as needed to deliver the message.

**Recipients:** the only recipient of messages is the tool's owner, who
configured their own number to receive them. There are no other end users.

**Contact:** the owner can be reached via the phone number associated with
this campaign.
